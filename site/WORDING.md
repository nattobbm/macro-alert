# 词库 · cypermow 专用

> **这份只管"这个站用哪个词"。** 通用的设计判断力（什么先出什么折叠、
> 数字怎么呈现、手机怎么验收）在 skill `tool-site-design` 里，不写在这。
> 分开是因为：词是这个站的，判断力是可以搬走的——混在一起，
> 下个站会被套上 cypermow 的词。
>
> 定稿 2026-09-01。以后加文案先查这张表，**不要另创说法**。
> 英文不是另写一套，是机翻中文（`index.html` 里的 translate.js）。
> 所以：**中文写好，英文自动好**；机翻唯一会错的是比喻词和人名，
> 那些登记在 `index.html` 的 `nomenclature` 里。

## 一条总规矩

**任何显示给人的数字，必须能用一句不带专业词的话说清"这是什么"和"往上意味着什么"。做不到就不该出现在页面上。**

行话不是不能出现，是不能**只**出现行话。两种合规写法：

1. 换成大白话 —— `盈亏平衡通胀>2.8` → `市场押注未来10年物价年涨 高于2.8%`
2. 保留行话 + 配一个点开就看得到解释的 `?` —— 快照卡的做法（词典在 `src/data/explain.ts`）

反面教材（2026-09-01 真事）：把 `▼0.03%` 改成 `▼3bp`。
数学修对了，但 bp 比原来更难懂——**修的是我的KPI（数据正确），不是用户的KPI（看得懂）**。

## 状态词：三个状态只有一套说法

| 状态 | 中文 | English | 用在哪 |
|---|---|---|---|
| 已经穿过警戒线 | **越线** | Crossed | 节点、计数卡、规则 |
| 还没穿但很近 | **快到** | Near | 同上 |
| 离得远 | **安静** | Quiet | 同上 |
| 前提被明确推翻 | **前提已翻** | premise broken | 节点、链卡 |

> 曾经的错误：节点说"越线/快到/安静"，首页计数卡说"活跃警报/临近阈值/状态正常"，
> 链卡又说"环破了"。**同一件事三套词。**「阈值」本身还是行话。已统一。

不要再用：`阈值` `触发` `告警` `环破` `活跃警报`。

### 状态标签不带语气词

`了` `过` `啦` 这类语气词一律去掉。状态标签要**名词感**，不要叙述感——
满屏都是"越线了""快到了""响了"，读起来很乱。

| ❌ | ✅ |
|---|---|
| 越线了 | 越线 |
| 快到了 | 快到 |
| 响了 / 响过(静音) | 已响 / 已响(静音中) |

例外：**句子**里可以有语气词（大白话解释、判据结论那些是在说话，不是标签）。
规矩只管标签、徽章、按钮这类"一个词"的地方。

## 数字必须带尺度（2026-09-02，Momo）

> 「我对数字没概念，感受不到数字变化的敏感度。我们做的东西就是帮人解读，而不是提供数学。」

**把数字直接算好，变小变简单**。两个数：比昨天收盘涨/跌多少**点**，今天最高到最低差多少**点**。
写法：`黄金 4427，比昨天 +79，今天高低差 90`。百分比放括号当尾巴：`（+1.8%）`。
只写 `黄金 4427 ↑1.82%` 是提供数学——1.82% 对没概念的人是空的，"+79" 不是。
不用"平时的几倍"这种二阶比例（她 9-02 否过）：那是抽象换抽象。
数据来源：`fetchers/market.py` 存了 `chg_1d / prev_close / open / high / low / day_range`。

## 推送（TG）专用

推送的段标题也是给人看的，**不许用我们内部的词**：

| ❌ 内部词 | ✅ 推送里写 |
|---|---|
| 快到线 | 再动一点就会触发的 |
| 预测单 | 你 8-31 签的 9-16 议息判断（说清签了什么、什么时候结算） |
| S1 / S2 / S3 | 加息 / 维持但话说得硬 / 维持且放软 |
| 撤资链开始 | 借日元炒美股的钱开始往回撤 |
| 剧本条件成立 1/3 | 剧本三个条件成立了一个 |
| 判据 | 8-25 报告写的"什么情况算它不成立"那条 |
| 官员原话（只贴原话） | 原话 + 下一行「意思：…」。政治语言故意模糊，只贴原话=让读者自己猜 |
| （没有现价） | 结论行下面固定一行 `现在 · 美股 7671 · 黄金 4430 · 日元 158.9 · 油 94.3 · 30年 5.25% · 加息 67%`。只放价不放涨跌；发出那一刻读最新的 quotes.json，旧超过1小时标时间 |

站内可以用"越线/快到/安静"（有"?"配解释）；推送没有"?"可点，**必须当场说清**。

## 人名 / 机构名不许意译

`萨姆规则=Sahm Rule`（是人名 Claudia Sahm，不是 Sam）、`泰勒缺口=Taylor gap`、
`菲利普斯曲线=Phillips curve`。这些都登记在 nomenclature 里。

## 单位

| 写法 | 什么时候用 | 点开"?"里必须解释 |
|---|---|---|
| `%` | 价格类涨跌幅 | 不用 |
| `bp` | 利率类，变化 < 1个百分点 | `1bp = 0.01%` |
| `pp` | 利率类，变化 ≥ 1个百分点 | `从4.1%到4.2%是涨0.1个百分点，不是涨0.1%` |

利率绝不用百分比表示变化：`4.67%→4.70%` 说成 `+0.6%` 反直觉，说成 `+3bp` 才不会看错位数。
但 **`bp` 必须配解释**，否则就是换了种黑话。

## 标点

- 中文用全角 `（）`，英文用半角 `()`。
  动态拼接时用 `isEN ? \`(...)\` : \`（...）\`` —— 写死全角会漏进英文页面。
- 分隔用 `·`，不用 `|` `/`。

## 文案描述界面行为的，界面改了必须跟着改

曾经的错误：小标题写着"按热度排序，横向滚动"，
但热度显示早就改成了「越线X·快到Y」，手机上也早就改成竖排了。**两句话都是假的。**
